# Conceito do Jogo

**Gênero:** Bullet Hell com Auto-Scroller vertical

**Tema:** Nave espacial tentando escapar de um planeta hostil

**Descrição geral:**
O jogador controla uma nave em um cenário de rolagem automática de cima para baixo. O objetivo é sobreviver enquanto foge de um planeta hostil, desviando de projéteis, destruindo inimigos e enfrentando ondas de perigo crescente.

## Elementos principais

**Personagem principal:**

* Uma nave espacial

**Inimigos:**

* Asteroides
* Criaturas orgânicas alienígenas inspiradas em enxames monstruosos

**Mecânicas centrais:**

* Movimento livre da nave
* Tiro do jogador
* Desvio de projéteis inimigos
* Auto-scroller vertical
* Colisão com inimigos e obstáculos
* Sistema de vida ou dano
* Condição de vitória ou fuga

## Estrutura das telas

1. Tela inicial
2. Tela de gameplay
3. Tela de pausa
4. Tela de game over
5. Tela de vitória após finalização do chefe

## Direção visual

* Cenário espacial com fundo em movimento
* Planeta hostil ao fundo ou na abertura
* Asteroides como ameaça ambiental
* Criaturas orgânicas com aparência agressiva e alienígena
* Sprites simples, feitos no Aseprite
* Interfaces desenhadas à mão no caderno

## Escopo recomendado

Para caber no prazo, o jogo pode ter:

* 1 nave jogável
* 3 tipos de inimigos
* 2 padrões de tiro
* 1 fase longa

## Objetivo do jogo

Sobreviver ao avanço pelo espaço hostil até escapar do planeta.
