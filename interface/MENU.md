# Menus

Os menus organizam o início e a navegação do jogo.

## Tela inicial

Tela exibida ao abrir o jogo.

### Opções

* Iniciar jogo
* Opções
* Sair

## Tela de pausa

Tela exibida durante a partida quando o jogador pausa o jogo.

### Opções

* Continuar
* Sair para o menu inicial

## Tela de game over

Tela exibida quando a nave é destruída ou a vida chega a zero.

### Opções

* Tentar novamente
* Sair para o menu inicial

## Tela de vitória

Tela exibida quando o jogador completa a fuga do planeta.

### Opções

* Jogar novamente
* Sair para o menu inicial

## Observação

Os menus devem ser simples, legíveis e rápidos de navegar, mantendo o foco na ação do jogo.
